# عادت‌کوئست (HabitQuest)

ردیاب عادت با حس بازی: امتیاز، سطح، زنجیره روزهای پشت‌سرهم و نمای هفتگی.

## اجرا
1. Android Studio (نسخه Koala یا جدیدتر) را باز کنید → Open → پوشه HabitQuest
2. صبر کنید Gradle Sync تمام شود (اینترنت لازم است)
3. گوشی یا شبیه‌ساز را وصل کنید و Run بزنید
4. برای APK: Build > Build Bundle(s) / APK(s) > Build APK(s)
